# Журнал подтверждённых ошибок manager-client

## Переписка пропадает из виджета после перезагрузки (12.10.2026)

- **Поведение:** посетитель отправляет сообщение и получает ответ, но после
  перезагрузки сайта видит новый пустой диалог. Исходные сообщения остаются
  на сервере, а доступ к своей сессии теряется в браузере.
- **Причина:** гостевой bearer-токен жил только в памяти WidgetApi. В localStorage
  сохранялся visitorToken для квот, который не подтверждает право чтения истории.
  Сервер уже поддерживает возврат snapshot по действующему гостевому токену.
- **Предотвращение:** сохранять только гостевой ключ публичного виджета с разделением
  по сервису, siteId и действительному origin родителя. Историю получать с сервера,
  не связывать доступ по телефону/email или visitorToken. Сбрасывать ключ только
  после HTTP 401, а не после сетевой ошибки. Не сохранять токен авторизованной
  поддержки, тексты, контакты, черновики или файлы. Учитывать отказ хранилища
  и не переносить загрузки/операции между старой и новой сессиями.
- **Проверка:** модульные проверки хранения и авторизации; полный браузерный набор,
  включая перезагрузку, переход на другую страницу, истёкшую сессию и production
  loader/iframe на разных origin. Продовая отправка реальным клиентам не используется.
  Если 4310 занят рабочим интерфейсом, задать `MANAGER_TEST_HOST_PORT` со свободным
  портом для страницы теста и `CI=1`, чтобы не переиспользовать чужие процессы.
  Демо API 4311 и preview 4312 должны быть свободны. Тестовый сервис не заменяет
  настоящий manager-server и не взаимодействует с продовыми базами.
