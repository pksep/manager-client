# Подключение готового виджета к сайту

Инструкция для человека, который добавляет виджет на свой сайт.
Файлы виджета и сервис сообщений размещает и обслуживает команда PKSEP.
Вам не нужно скачивать репозиторий, устанавливать зависимости, собирать виджет
или переносить его файлы на свой хостинг.

После подключения посетители смогут писать в чат на сайте, а наши операторы —
отвечать им из раздела «Клиенты» в СЭП Чате.

## 1. Получить готовый код подключения

Передайте команде PKSEP домены страниц, где должен работать виджет.
Если используются адреса с `www`, без `www` или тестовый домен, укажите каждый
из них. Подключаемый сайт должен работать по HTTPS.

Команда PKSEP разрешит эти домены на своей стороне и передаст готовый код
для вашего сайта. В нём уже будут указаны идентификатор сайта и рабочие адреса
нашего виджета и сервиса сообщений. Подбирать или настраивать их самостоятельно
не нужно. Ключи ВК, Чата, ERP и CAPTCHA для подключения не требуются.

## 2. Вставить выданный код на страницы

Добавьте код **один раз** в общий подвал сайта, перед `</body>`, либо в блок
пользовательских скриптов конструктора/CMS, который выполняется после создания
страницы. Если чат нужен на всех страницах, используйте общий шаблон сайта.

Виджет и сервис сообщений размещены на `https://manager.pksep.ru`.
Ниже показан код с нашим адресом, но `amotiv-site` — пример идентификатора сайта.
Рабочий `siteId` подставляет **команда PKSEP**, а интегратор вставляет выданный
фрагмент целиком. Самостоятельно выбирать идентификатор не нужно.

```html
<script src="https://manager.pksep.ru/manager.js"></script>

<script>
  if (!window.sepManagerWidget) {
    window.sepManagerWidget = SepManager.mount({
      siteId: 'amotiv-site',
      serviceUrl: 'https://manager.pksep.ru',
      widgetUrl: 'https://manager.pksep.ru/widget.html',
      offset: 24,
    })
  }
</script>
```

Вставляйте именно полученный рабочий код с идентификатором вашего сайта,
а не пример с `amotiv-site`.
Не добавляйте `async` на загрузчик и не меняйте порядок двух скриптов:
инициализация выполняется после загрузки виджета.
Отдельный контейнер, кнопка или собственные стили для чата не нужны.

Для сайта без полной перезагрузки страниц подключайте виджет один раз
в корневом шаблоне после создания DOM. Не пересоздавайте его при каждом переходе
и не удаляйте при переключении пользователя на другую вкладку.

## 3. Проверить работу

### Необязательные настройки первого сообщения и открытия

Добавьте параметры непосредственно в выданный `SepManager.mount({...})`:

```js
initialMessage: 'Здравствуйте! Подскажите, чем мы можем помочь?',
autoOpenDelayMs: 3000,
```

`initialMessage` — обычный текст до 2000 символов, показанный перед первым
обращением вместо стандартных вариантов ответа. Посетитель пишет ответ,
после чего видит ту же форму контактов. Только после её заполнения ответ
и контакты отправляются оператору. Приветствие — локальная подсказка сайта:
оно не создаёт отдельного сообщения или обращения на сервере. После создания
обращения подсказка скрывается. HTML в тексте не выполняется.

`autoOpenDelayMs` — целое число миллисекунд от вызова `SepManager.mount`:
`3000` означает 3 секунды, `0` — открытие сразу после готовности сервиса.
Допустимый диапазон — от `0` до `3600000` (1 час). Без этого параметра
автоматическое открытие по таймеру выключено; `initialMessage` можно использовать
и при ручном открытии. Без обоих параметров поведение виджета не меняется.

Таймер открывает виджет один раз за экземпляр на странице, не забирая фокус.
Если посетитель уже открыл/закрыл чат или у него восстановлен текущий диалог,
повторного открытия по таймеру нет. При скрытой вкладке или недоступном сервисе
виджет ждёт возвращения и готовности, не начиная отсчёт заново.

### Свои стили и ссылка ВКонтакте

В том же `SepManager.mount({...})` можно добавить:

```js
showVk: true,
vkUrl: 'https://vk.ru/im/convo/-203143723?entrypoint=list_all',
customCss: `
  .manager-widget { --chat-window-radius: 16px; }
  .launcher { background: #164f43; }
  .chat-header { background: #e8f4ef; }
`,
```

`showVk: true` показывает существующий пункт ВКонтакте. `vkUrl` задаёт адрес
чата или сообщества и заменяет серверную ссылку ВК, не создавая второй пункт.
`showVk: false` скрывает ВК даже при наличии ссылки на сервере. Если параметры
не указаны, сохраняется меню сервера. Для нового пункта нужна ссылка:
одного `showVk: true` без `vkUrl` и без серверной ссылки недостаточно.

Указанный адрес открывается по нажатию в новой вкладке. ВК может запросить
авторизацию. Если для вашей аудитории удобнее переход в сообщество, замените
`vkUrl` на `https://vk.ru/npoamotiv`. Разрешены HTTPS-адреса `vk.ru`, `vk.com`
и `vk.me`, без логина и пароля. Пункт меню не подключает приём сообщений ВК:
эта интеграция отдельно настраивается на сервере.

`customCss` принимает CSS-текст до 16000 символов. Он действует только внутри
изолированного окна виджета, не меняя страницу сайта. HTML и JavaScript сюда
вставлять не нужно. Пустая строка или отсутствие параметра сохраняет стандартные
стили. Доступные классы для оформления: `.manager-widget`, `.launcher`,
`.chat-window`, `.chat-header`, `.composer` и `.contact-menu`.

Настройка предназначена для доверенного кода владельца сайта. Не подставляйте
сюда текст посетителей. CSS может загружать внешние шрифты и картинки, если
это разрешено политикой безопасности самого виджета. Предпочитайте цвет,
шрифт и фон; изменение размеров, `display`, `position`, `overflow`, `transform`
или анимаций может нарушить открытие и размещение окна. Геометрия внешнего
iframe этой настройкой не меняется, отступ задаётся через `offset`.

Для проверки локально нажмите «Пример CSS и ВК» на тестовой странице,
затем «Применить конфиг». Отредактированный JSON можно скачать.

### Проверка подключения на сайте

1. Откройте сайт и убедитесь, что кнопка чата появилась.
2. Отправьте тестовое сообщение, заполнив необходимые контакты.
3. Вместе с оператором проверьте, что сообщение появилось в СЭП Чате,
   а ответ оператора вернулся в виджет.
4. Проверьте отображение на телефоне и на остальных страницах сайта.
   После отправки и ответа перезагрузите страницу и снова откройте чат:
   текущая переписка должна восстановиться без повторного заполнения контактов.
5. При необходимости проверьте разрешённый файл и переход на другую вкладку:
   открытая страница должна продолжать получать ответы.

Новый ответ и начало набора оператором открывают окно чата без захвата фокуса.
Звуковое уведомление зависит от настроек браузера и обычно доступно после первого
действия посетителя на странице. При полностью закрытой странице уведомления
этой интеграции не доставляются.

Отправленная переписка восстанавливается в том же браузере, для того же сайта
и пока действительна сессия. Если посетитель очистил данные сайта, использует
другой браузер или браузер запрещает хранилище виджета, откроется новый диалог.
Это не перенос истории по одному имени, телефону или email.
Переписки, ключ к которым был потерян до обновления виджета, автоматически
не открываются: сохраняются только сессии, начатые или восстановленные новой версией.

Если сам сервис временно недоступен, виджет может скрываться до восстановления.
Вне рабочего времени исправный виджет остаётся доступным со статусом оператора
«не в сети».

## Если кнопки нет или сообщения не отправляются

- Проверьте, что вставлен весь выданный код с идентификатором вашего сайта.
- Убедитесь, что домен страницы совпадает с тем, который передали нашей команде.
- Проверьте, что CMS или конструктор не удалил скрипты и не изменил их порядок.
- Если ваш сайт ограничивает сторонние скрипты и iframe политикой безопасности
  содержимого (CSP), передайте выданный код администратору сайта: он должен
  разрешить наши адреса, сохранив остальные ограничения. Не отключайте защиту
  сайта целиком.
- Если запрещены встроенные скрипты, администратор сайта может вынести
  инициализацию в разрешённый JS-файл или использовать штатный nonce сайта.

Если это не помогло, передайте команде PKSEP адрес проблемной страницы,
описание поведения и безопасный текст ошибки из браузера.
Не присылайте пароли, `Authorization`, гостевые токены или контакты посетителей.

## Что остаётся на стороне PKSEP

История в публичном виджете доступна до 24 часов с момента начала сессии;
перезагрузка страницы не продлевает этот срок. Затем виджет очищает локальный
доступ и загруженные данные и начинает пустой диалог. Если вкладка была закрыта
или приостановлена, очистка выполняется при следующем запуске или возвращении.
У операторов в СЭП Чате отправленные сообщения и вложения сохраняются:
срок виджета не удаляет серверную переписку. Тексты и контакты не записываются
в постоянное хранилище браузера.

Мы размещаем и обновляем виджет, выдаём готовый код, разрешаем домены,
настраиваем приём сообщений, CAPTCHA и связь с операторами.
Разработчик вашего сайта отвечает только за размещение выданного кода
и совместимость с настройками безопасности своего сайта.
