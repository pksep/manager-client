# Журнал ошибок manager-client

## 2026-09-11 — лишняя ширина контактов и задержка эмодзи

**Симптом:** короткий текст уже сжимался, но строка имени, телефона и email
оставляла много свободного места. Эмодзи долго открывались после отправки.

**Причина:** fit-content сохраняет доступную ширину при переносах; прежняя
проверка измеряла только короткое сообщение, а не контакты. Редактор
пересоздавался, а программный выбор первой категории эмодзи запускал расчёт
всех категорий.

**Предотвращение:** измерять фактические строки с учётом времени и галочек,
пересчитывать при изменении ширины и загрузке шрифта. Сохранять редактор и
готовить эмодзи заранее без повторного выбора категории.

**Проверка:** браузерный сценарий компактности проверяет переносы контактов,
ширину и отсутствие пересечения со временем. Сценарий эмодзи проверяет
предзагрузку, сохранение экземпляра, выбор категории и повторную отправку.

## 2026-09-11 — обрезанная тень в зазоре меню

**Симптом:** между меню способов связи и круглой кнопкой виден фрагмент тени.

**Причина:** внешняя тень меню обрезалась фигурной границей iframe,
оставляя прямоугольный участок над кнопкой.

**Предотвращение:** отключать внешнюю тень только у этого меню; прозрачный
проход курсора между кнопкой и меню относится к области launcher-area.

**Проверка:** меню остаётся открытым при остановке курсора в зазоре дольше
задержки закрытия; браузерная проверка и снимок на контрастном фоне.

## 2026-09-11 — старый экспорт после замены локальной сборки sep-yui

**Симптом:** браузер сообщает, что `@pksep_yui.js` не экспортирует
ChatMessageMeta; виджет не появляется, хотя типы и сборка корректны.

**Причина:** overlay заменяет dist без изменения версии и lockfile,
поэтому Vite повторно использует ранее предсобранный пакет.

**Предотвращение:** после обновления локальной библиотеки перезапускать
стенд командой `bun run demo --force` (или `bun run dev --force` при раздельном
запуске). Флаг передаётся Vite для штатной пересборки кэша; обычный запуск
демо сохраняет прежнее поведение. После публикации закреплять новую версию.

**Проверка:** открытие виджета в браузерном сценарии и отсутствие ошибки
недостающего экспорта; одной проверки TypeScript недостаточно.

## 2026-09-11 — разное оформление редактора и неполные статусы сообщений

**Симптом:** рамка редактора скруглялась сильнее родителя; плашки занимали
лишнюю ширину, у контактов отсутствовали время и галочки. Недоступная
кнопка отправки не объясняла причину.

**Причина:** адаптивный радиус ContentEditor наследовался из общих стилей,
сообщения имели отдельную flex-колонку текста, а контакты рендерились простым
текстом без метаданных. Обработчик событий игнорировал обновление существующего
сообщения; модель содержала только факт отправки. Валидация возвращала boolean.

**Предотвращение:** наследовать радиус контейнера локально; использовать
оболочку по ширине содержимого и общий ChatMessageMeta во всех видах сообщений.
Обновлять readAt без дублирования/сброса статуса, в том числе при позднем HTTP.
Получать причину Tooltip из той же проверки, которая разрешает отправку.

**Автоматическая проверка:** сценарии «причина disabled», «текст и контакты
компактны» и «прочтение до HTTP-подтверждения» проверяют hover/focus, радиусы,
компактность, время и обе отметки, восстановление и запоздавшее подтверждение.

## 2026-09-11 — раскладка и пустая отправка в узком редакторе

**Симптом:** вложения и эмодзи находились справа; кнопка отправки была активна
при пустом поле, хотя макет предусматривает disabled.

**Подтверждённая причина:** внутри iframe срабатывали адаптивные стили общего
ContentEditor, сжимающие панель инструментов. Параметр `active-send` принудительно
разрешал пустую отправку на уровне кнопки (пустой запрос блокировал виджет).

**Предотвращение:** не передавать `active-send`, когда требуется штатная проверка
содержимого. Локально растягивать панель редактора по ширине окна, сохранять
левые действия и автоматический отступ перед отправкой. Не менять общие стили
библиотеки для особенностей одного iframe.

**Проверка:** начальный браузерный сценарий проверяет disabled до ввода и enabled
после выбора готовой фразы; сценарии файлов и эмодзи проверяют доступность
действий. При визуальной проверке сравнить расположение кнопок с SVG.

## 2026-09-11 — недоступна ссылка на локальное демо

**Симптом:** после передачи локального адреса страница не открывается.

**Подтверждённая причина:** при проверке не было слушающих процессов на портах
4310 (страница) и 4311 (демонстрационный сервис). Ранее стенд запускался двумя
отдельными временными процессами; их запуск не обеспечивает постоянную
доступность ссылки.

**Предотвращение:** единая команда `bun run demo` запускает оба процесса,
проверяет зависимости и порты, сообщает о готовности только после ответа обоих
сервисов и завершает стенд при неожиданной остановке одного из них. Инструкция
явно требует оставлять команду работающей и повторять запуск после остановки.

**Проверка перед передачей:** выполнить `bun run demo`, дождаться готовности,
запустить существующий браузерный сценарий «геометрия, приветствия и контакты
до первой доставки» — он проверяет открытие виджета, заполнение контактов,
отправку и ответ. Повторный запуск при занятых портах должен завершаться с
понятной ошибкой и сохранять уже работающий стенд. После проверки убедиться,
что оба адреса по-прежнему доступны.
